# 💑 우리 함께 핏 (Couple Fit) - 커플 다이어트 & 운동 메이트

여자친구(iPhone)와 나(Android)를 위한 **100% 무료 커플 다이어트 & 운동 관리 앱**입니다.

---

## ✨ 핵심 기능 완벽 구현

1. **👟 운동 출석 체크 & 하트 달력**
   - **원탭 출석**: 오늘 운동 완료 버튼을 누르면 즉시 도장 기록
   - **커플 하트 연동**: 둘 다 완료한 날은 달력에 반짝이는 핑크 하트(`💖`) 자동 생성
   - **스트릭 & 달성률**: 연속 출석 일수(`3일 연속`) 및 이번 주 달성률(`85%`) 실시간 집계

2. **📊 걸음 수 / 걷기 기록**
   - 폰 건강 앱(Apple Health / 삼성 헬스) 숫자를 간단히 입력
   - 오동원(파랑) vs 김해솔(분홍) 주간 걸음 수를 파스텔 막대 그래프로 한눈에 비교

3. **⚖️ 비공개 체중 기록장 (비교 스트레스 ZERO)**
   - **내 화면**: 실제 몸무게(kg)와 감량 수치 표시
   - **파트너 화면**: 실제 숫자는 🔒 비공개 처리되고, **"시작 대비 -1.2kg 감량 성공 중! 👏"** 변화량만 공유되어 서로 스트레스 없이 격려 가능

4. **🥗 식단 사진 일기 (칼로리 스트레스 ZERO)**
   - 번거로운 칼로리 계산 없이 사진 1장 + 한 줄 메모로 기록
   - 기기 내 자동 압축으로 빠른 로딩 및 데이터 절약

5. **⚔️ 주간 미션 대결 & 귀여운 벌칙**
   - "이번 주 5일 걷기", "스쿼트 200개" 등 목표 대결
   - 실시간 진행률 게이지 + 벌칙("진 사람이 주말에 디저트 사기 🍰")

6. **💌 실시간 칭찬 & 응원 한마디**
   - 운동 완료 후 터치 한 번으로 상대방에게 하트 팝업 응원 메시지 전송

7. **🎁 커플 보상 상자 (데이트 쿠폰)**
   - 함께 운동해서 모은 하트가 쌓이면 특별 데이트 쿠폰 해금 (스타벅스 쿠폰, 치팅데이 맛집 투어권, 마사지 쿠폰 등)

8. **⏱️ 홈트레이닝 운동 루틴 타이머**
   - 운동 시간(45초) / 휴식 시간(15초) / 세트 수 맞춤 설정
   - 원형 게이지 + 비프음 알림 (모든 세트 완료 시 오늘 출석 자동 반영)

## 🚀 1. 내 컴퓨터에서 바로 실행해보기

바탕화면의 `couple_diet_app` 폴더에서 아래 명령어 중 하나를 실행하거나, `index.html` 파일을 더블 클릭하여 바로 열 수 있습니다:

```bash

python couple_diet_app/run_server.py
```

## 📱 2. 아이폰 & 안드로이드에서 앱처럼 설치하기 (PWA)

### 방법 A: GitHub Pages로 1분 만에 100% 무료 배포 (추천)
1. GitHub 무료 계정에서 새 저장소(Repository)를 만듭니다.
2. `couple_diet_app` 안의 파일들을 업로드합니다.
3. GitHub 저장소의 **Settings -> Pages -> Branch를 `main`으로 설정 후 Save**를 누릅니다.
4. 1분 뒤 무료 주소(예: `https://yourname.github.io/couple-diet`)가 생성됩니다.

### 방법 B: 스마트폰에 앱으로 등록하기
* **여자친구 아이폰 (Safari)**: 해당 웹 주소 접속 $\rightarrow$ 하단 공유 버튼 클릭 $\rightarrow$ **'홈 화면에 추가'**
* **내 안드로이드 폰 (Chrome)**: 해당 웹 주소 접속 $\rightarrow$ 상단 메뉴(점 3개) 클릭 $\rightarrow$ **'앱 설치'** 또는 **'홈 화면에 추가'**

👉 두 기기 모두 일반 앱스토어에서 받은 앱처럼 **전체 화면 아이콘**으로 깔끔하게 동작합니다.

## ☁️ 3. Supabase 무료 클라우드 실시간 연동 (선택사항)

기본적으로 브라우저 로컬 저장소로 바로 사용 가능하며, 두 폰 간 실시간 클라우드 동기화를 원할 경우:

1. [Supabase](https://supabase.com)에 무료 가입 후 새 프로젝트를 생성합니다.
2. Supabase의 **SQL Editor**에 본 프로젝트의 `supabase_schema.sql` 내용을 복사하여 실행합니다.
3. 앱 상단 오른쪽 **톱니바퀴(⚙️)** 설정에서 Supabase `Project URL`과 `Anon Key`를 입력하면 자동으로 실시간 클라우드 DB와 연동됩니다.
